    落としやすい点
    
        
      
          
    1. 特権パスワードは 2 種類ある。enable secret はハッシュ化して保存され、enable password は平文で保存される。両方あると enable 時に求められるのは secret の方。
      2. 
          
    2. service password-encryption を打つと既存のパスワードが 7 xxxx 形式に変わり、no service password-encryption で戻しても平文には戻らない（パスワードの再入力が必要）。
      3. 
          
    3. パスワード認証を有効にするのは login。password だけでは認証は掛からない。コンソールと VTY の両方で、2つ1組。
      4. 
          
    4. no shutdown を忘れると show run のインタフェースに shutdown 行が残る。ケーブル未接続なら状態は down のままで正常（administratively down でなければ有効化はできている）。
      5. 
          
    5. 現在の設定は running-config。設定モードのままなら do show running-config。startup-config は保存済みの設定で別物。
      6. 
          
    6. 説明文・バナー・パスワード・ホスト名は大文字小文字を区別する。Authorized-Access のハイフンも指示どおりに打つ。
      7. 
          
    7. banner motd の区切り文字（# など）は本文に出てこない文字を使う。閉じ忘れると複数行入力モードになるので、もう一度 # を打てば終わる。
      8. 
          
    8. 名前解決を無効化する前に打ち間違えると Translating... で待たされる。⑤ は早めに入れておくと楽。
      9. 
          
    9. transport input telnet は、VTY でどのプロトコルの接続を受け付けるかの指定。機器の既定値によっては Telnet が通らないことがある。採点の対象にするかは画面のチェックで選べる。
      10. 
          
    10. VTY の範囲は line vty 0 4。機種によっては 0 15 まで指定できるので、指示された範囲に合わせる。
