    プロンプトの見分け方
    
        
    
          
    
            
    [student@server1 ~]$一般ユーザー。~ はホームディレクトリにいる印
    
            
    sudo -i か su -→
    
            
    [root@server1 ~]#root。# で終わる
    
            
    exit→
    
            
    [student@server1 ~]$元のユーザーに戻る
    
          
    
          
    
            
    [student@server1 docs]$~ の位置には今いるディレクトリの名前だけが出る
    
            
    >入力の続きを待っている。引用符の閉じ忘れか、行末の | など。Ctrl+C で取り消し
    
            
    [sudo] password for student:sudo は自分のパスワードを聞く
    
            
    Password:su は切り替え先のパスワードを聞く
    
          
    
        
    
      
    

      
    
        
    ls -l の読み方
    
        
    -rw-r-----. 1 student dev  1024 Nov  9 10:00 report.txt
│└┬┘└┬┘└┬┘  │ └──┬──┘ └┬┘  └┬─┘ └────┬─────┘ └───┬────┘
│ │  │  │   │    │     │    │        │           └ 名前
│ │  │  │   │    │     │    │        └ 最終更新日時（半年より前は年を表示）
│ │  │  │   │    │     │    └ サイズ（バイト）
│ │  │  │   │    │     └ グループ
│ │  │  │   │    └ 所有者
│ │  │  │   └ ハードリンクの数
│ │  │  └ その他のユーザー（o）
│ │  └ グループ（g）
│ └ 所有者（u）
└ 種類（- ファイル、d ディレクトリ、l シンボリックリンク、c と b はデバイス）
  r=4  w=2  x=1  →  rw-=6  r-x=5  r--=4  ---=0
  特殊な権限：SUID は所有者の x が s、SGID はグループの x が s、スティッキービットはその他の x が t
  RHEL 系では権限の後に SELinux の印「.」が付く（このドリルでは省略）
