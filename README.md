# 学習ツール集

ネットワークと基本情報技術者試験の学習用に作った、ブラウザで動く 3 つのツールです。

**公開ページ：** https://yamagata-inaka.github.io/study-tools/

| ツール | 内容 |
|---|---|
| [ルータ基本設定ドリル](https://yamagata-inaka.github.io/study-tools/router-drill/) | Cisco IOS ルータの初期設定を疑似コンソールで練習する |
| [サブネット計算ドリル](https://yamagata-inaka.github.io/study-tools/subnet-drill/) | CCNA のサブネット計算を反復練習する |
| [科目B 完走コース](https://yamagata-inaka.github.io/study-tools/kamoku-b/) | 基本情報技術者試験 科目B を 171 問・16 ステージで対策する |

## 全体の設計

- **サーバーを持たない：** すべて静的な HTML と JavaScript です。ビルドは不要で、ページをそのまま配信できます。
- **データを外部に送らない：** 成績や設定は閲覧者のブラウザの `localStorage` にだけ保存します。外部から読み込むのは Google Fonts だけです。
- **依存を増やさない：** フレームワークやライブラリを使わず、素の JavaScript で書いています。

## ルータ基本設定ドリル

**目的：** 実機がない環境でも、コマンド入力から設定確認までの流れを手で覚えられるようにします。

**設計のポイント：**

- **構文木によるコマンド解析：** コマンドを木構造で定義し、実機に近い省略入力と Tab 補完を実現しています。省略形を禁止するモードもあり、正式なコマンド名の練習にも使えます。
- **設定の状態で採点：** 入力履歴ではなく、最終的な設定の内容を採点します。設定の順序が違っても、結果が正しければ正解になります。
- **つまずきの再現：** 打ち間違いをホスト名とみなして名前解決で待たされる動作など、実機で起きることを再現し、`no ip domain-lookup` が必要な理由を体感できるようにしています。
- **4 つの学習形式：** 通し練習、一問一答、四択、早見表を切り替えられます。ランダム問題では値が毎回変わるので、答えの丸暗記を防げます。

実機の完全な再現ではなく、初期設定の練習に必要な範囲のコマンドだけを扱います。パスワードのハッシュ表示なども練習用の模擬です。

## サブネット計算ドリル

**目的：** サブネット計算を、考え方を理解したうえで素早くできるようにします。

**設計のポイント：**

- **32 ビット整数として計算：** IPv4 アドレスを符号なし 32 ビット整数として扱います。JavaScript のビット演算は符号付きになるため、`>>> 0` で符号なしに戻しています。
- **問題の自動生成：** 出題範囲（`/24`〜`/30`、`/16`〜`/30`、`/8`〜`/30`）と 11 種類の問題形式を選べ、問題を毎回ランダムに作ります。
- **解説は 2 進数で表示：** 答え合わせのあと、ネットワーク部とホスト部を 2 進数で確認できます。
- **入力の負担を減らす：** 全角数字や全角ピリオドも受け付け、IP アドレス欄では `.` を自動で補います。問題形式ごとの正答率も記録します。

## 科目B 完走コース

**目的：** 基本情報技術者試験 科目B を、易しい問題から公開問題まで順番に進めて完走できるようにします。

**設計のポイント：**

- **分野と難易度で分けたコース：** IPA の問題 71 問とオリジナル問題 100 問を 16 ステージに並べています。アルゴリズムは易しい問題から順に進み、セキュリティ問題 50 問は専用の 4 ステージにまとめました。最後は令和 5〜8 年度のアルゴリズムの公開問題です。
- **セキュリティ問題の並び順：** 問題文の字数、表の数、選択肢の数から計算した読解量の目安で並べています。正答率の実測にもとづく難易度ではありません。
- **解く手順を教える解説：** 答えだけでなく、「設問と選択肢を先に見る」「選択肢の違いを見る」「小さい例でトレースする」といった読み方の手順に沿って解説します。
- **データと画面の分離：** 問題データ、ステージ構成（`course.js`）、画面の処理（`index.html`）を分けているので、画面を変えずに問題の追加や並べ替えができます。
- **復習の仕組み：** 問題ごとに初回と最後の正誤を記録し、ステージ内の間違えた問題を解き直せます。
- **出典の明示：** IPA の問題には各問に出典を表示し、オリジナル問題と区別しています。

### IPA の問題と原本の照合

71 問すべてについて、問番号と正解が IPA の公表資料と一致することをスクリプトで確認しました。Web 表示のために図表の組み直しや文章化、文言の調整をしているため、各問の出典に「一部改変」と記載しています。解説は IPA によるものではありません。
