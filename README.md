# 学習ツール集

ネットワーク、データベース、基本情報技術者試験の学習用に作った、ブラウザで動く 4 つのツールです。

**公開ページ：** https://yamagata-inaka.github.io/study-tools/

| ツール | 内容 |
|---|---|
| [ルータ基本設定ドリル](https://yamagata-inaka.github.io/study-tools/router-drill/) | Cisco IOS ルータの初期設定を疑似コンソールで練習する |
| [サブネット計算ドリル](https://yamagata-inaka.github.io/study-tools/subnet-drill/) | CCNA のサブネット計算を反復練習する |
| [MySQL 基本操作ドリル](https://yamagata-inaka.github.io/study-tools/mysql-drill/) | MySQL の接続、SQL、トランザクション、権限を疑似コンソールで練習する |
| [科目B 完走コース](https://yamagata-inaka.github.io/study-tools/kamoku-b/) | 基本情報技術者試験 科目B を 171 問・16 ステージで対策する |

## 制作の役割分担

このリポジトリは AI（Anthropic の Claude、Claude Code）を使って作りました。

| 担当 | 内容 |
|---|---|
| **制作者** | 何を作るかのアイデア、実際に使っての問題発見、修正内容の決定、公開するかの判断と責任 |
| **Claude** | コードの実装、問題と解説の作成、原本との照合、テスト、この README の執筆 |

コードは制作者が 1 行ずつ書いたものではありません。以下の「設計」の説明も、実装内容をもとに Claude がまとめたものです。

## 全体の設計

- **サーバーを持たない：** すべて静的な HTML と JavaScript です。ビルドは不要で、ファイルをそのまま配信できます。
- **データを外部に送らない：** 成績や設定は閲覧者のブラウザの `localStorage` にだけ保存します。外部から読み込むのは Google Fonts だけです。
- **依存を増やさない：** フレームワークやライブラリを使っていません。

## ルータ基本設定ドリル

**目的：** 実機がない環境でも、コマンド入力から設定確認までの流れを手で覚えられるようにします。

- **構文木によるコマンド解析：** コマンドを木構造で定義し、実機に近い省略入力と Tab 補完を実現しています。省略形を禁止するモードもあります。
- **設定の状態で採点：** 入力履歴ではなく最終的な設定を採点するので、順序が違っても結果が正しければ正解になります。
- **つまずきの再現：** 打ち間違いで名前解決を待たされる動作などを再現し、`no ip domain-lookup` が必要な理由を体感できます。
- **4 つの学習形式：** 通し練習、一問一答、四択、早見表を切り替えられます。ランダム問題では値が毎回変わります。

初期設定の練習に必要な範囲だけを扱う模擬で、実機の完全な再現ではありません。パスワードのハッシュ表示なども練習用です。

## サブネット計算ドリル

**目的：** サブネット計算を、考え方を理解したうえで素早くできるようにします。

- **32 ビット整数として計算：** IPv4 アドレスを符号なし 32 ビット整数として扱います。JavaScript のビット演算は符号付きになるため、`>>> 0` で符号なしに戻しています。
- **問題の自動生成：** 3 段階の出題範囲（`/24`〜`/30`、`/16`〜`/30`、`/8`〜`/30`）と 11 種類の問題形式を選べます。
- **2 進数の解説：** 答え合わせのあと、ネットワーク部とホスト部を 2 進数で確認できます。
- **入力の補助：** 全角の数字やピリオドも受け付け、IP アドレス欄では `.` を自動で補います。

## MySQL 基本操作ドリル

**目的：** サーバーを用意しなくても、ログインから SQL の実行、権限の確認までの流れを手で覚えられるようにします。

- **SQL を解釈する自作エンジン：** 字句解析、構文解析、名前解決、実行を JavaScript で実装しています。結合、集計、サブクエリ、外部キー、トランザクション、権限を扱えます。
- **結果と状態で採点：** 入力した文字列ではなく、実行後のデータや定義、表示された結果を採点します。別名を付けた SQL など、書き方が違っても結果が正しければ正解です。
- **つまずきの再現：** `;` を忘れたときの `->` プロンプト、引用符の閉じ忘れ、WHERE のない UPDATE、外部キー違反、権限不足を、実物と同じ表示で体験できます。
- **4 つの学習形式：** 通し練習（15 項目）、一問一答（44 項目）、四択（64 問）、早見表を切り替えられます。通し練習のランダム問題と一問一答では値が毎回変わります。

**実物との比較：** MySQL 9.7.2 に同じ SQL を流し、出力を比べました。

| 比較した内容 | 文の数 | 一致 |
|---|---|---|
| エラー文や表示形式を確かめる SQL | 208 | 202 |
| 3 問の模範解答、一問一答の模範解答、四択の根拠になる動作 | 568 | 568 |

比較では実行時間を除きました。2 つ目の比較では、ORDER BY のない結果の行順も問いません。1 つ目で一致しなかった 6 文の内訳は、行順が保証されない結合 1 文、実行時刻を含む結果 2 文、対象外にした UNION とビューの 3 文です。予約語の一覧は、実物の `information_schema.KEYWORDS` から取得しました。

基本操作の範囲だけを扱う模擬で、実機の完全な再現ではありません。ビュー、トリガー、ストアドプロシージャ、ウィンドウ関数などは実行できません。`root` の `SHOW GRANTS` は簡略化しています。

## 科目B 完走コース

**目的：** 基本情報技術者試験 科目B を、易しい問題から公開問題まで順番に進めて完走できるようにします。

- **分野と難易度で分けたコース：** IPA の問題 71 問とオリジナル問題 100 問を 16 ステージに並べています。セキュリティ問題 50 問は専用の 4 ステージにまとめ、最後は令和 5〜8 年度のアルゴリズムの公開問題です。
- **解く手順を教える解説：** 「設問と選択肢を先に見る」「選択肢の違いを見る」「小さい例でトレースする」といった読み方の手順に沿って解説します。
- **データと画面の分離：** 問題データ、ステージ構成（`course.js`）、画面の処理（`index.html`）を分けています。
- **復習の仕組み：** 問題ごとに初回と最後の正誤を記録し、間違えた問題を解き直せます。

セキュリティ問題の並び順は、問題文の字数、表の数、選択肢の数から計算した読解量の目安です。正答率の実測にもとづく難易度ではありません。

### IPA の問題と原本の照合

71 問すべてについて、問番号と正解が IPA の公表資料と一致することをスクリプトで確認しました。Web 表示のために図表の組み直しや文章化、文言の調整をしているため、各問の出典に「一部改変」と記載しています。解説は IPA によるものではありません。
